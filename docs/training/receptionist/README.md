## Objetivo do Treinamento

Capacitar o profissional de recepção a utilizar todas as funcionalidades do SMG de forma autônoma, garantindo atendimento de excelência, organização operacional e conformidade com os fluxos de trabalho estabelecidos pela barbearia.

Ao final deste treinamento, o recepcionista será capaz de:

- Receber e identificar clientes presencialmente e por telefone
- Cadastrar e gerenciar informações de clientes
- Criar, editar e cancelar agendamentos na agenda
- Abrir e gerenciar comandas
- Realizar checkout com diversos métodos de pagamento
- Visualizar produtos, estoque e receber pagamentos
- Utilizar o sistema mesmo sem conexão com a internet
- Comunicar-se com clientes via lembretes e follow-ups

---

## Pré-requisitos

- Acesso ao sistema SMG com credenciais fornecidas pelo gestor
- Dispositivo com navegador atualizado (Chrome, Firefox, Safari ou Edge)
- Conexão com a internet (para uso normal; offline é exceção)
- Conhecimento básico de informática e uso de sistemas web
- Leitura e compreensão deste manual completo

## Módulo 01 — Primeiro Acesso

### 1.1 Login

1. Acesse o endereço fornecido pelo gestor (ex: `https://sua-barbearia.soumanager.com`)
2. Clique em **Entrar**
3. Insira o **e-mail** e **senha** fornecidos
4. Clique em **Entrar**

### 1.2 Alteração de Senha

Após o primeiro login, **obrigatoriamente** altere sua senha:

1. Acesse **Configurações** → **Meu Perfil**
2. Clique em **Alterar Senha**
3. Insira a senha atual
4. Insira a nova senha (mínimo 8 caracteres, com letra maiúscula, minúscula e número)
5. Confirme a nova senha
6. Clique em **Salvar**

> ⚠️ Nunca compartilhe sua senha. Em caso de suspeita de acesso não autorizado, reporte imediatamente ao gestor.

### 1.3 Configuração do Perfil

1. Verifique se seu nome está correto
2. Adicione uma foto de perfil (opcional mas recomendado)
3. Verifique seu horário de trabalho atribuído
4. Confirme seu role: **Recepcionista**

### 1.4 Visão Geral do Dashboard

O Dashboard é a primeira tela que você verá após o login. Ele contém:

- **KPIs do dia**: total de agendamentos, faturamento do dia, clientes atendidos
- **Próximos agendamentos**: lista cronológica dos agendamentos do dia
- **Alertas**: notificações importantes que precisam de atenção
- **Atalhos rápidos**: botões para as funções mais usadas

**Componentes do Dashboard:**

| Componente | Descrição |
|------------|-----------|
| Cartão de Agendamentos | Quantidade total de agendamentos do dia |
| Cartão de Faturamento | Valor total recebido no dia |
| Cartão de Clientes | Número de clientes atendidos |
| Lista de Próximos | Próximos 5 agendamentos com horário e profissional |
| Alertas | Notificações pendentes, lembretes, etc. |

### 1.5 Navegação pela Interface

A navegação do sistema é feita pelo **menu lateral** (sidebar):

- **Dashboard**: Visão geral do dia
- **Agenda**: Calendário e agendamentos
- **Clientes**: Cadastro e gestão de clientes
- **Comandas**: Ordens de serviço abertas
- **PDV**: Ponto de venda / checkout
- **Produtos**: Catálogo e estoque
- **Recebimentos**: Pagamentos do dia
- **Comunicação**: Lembretes e follow-ups
- **Suporte**: Tickets de suporte

> **Dica**: Use o atalho `Ctrl + K` (ou `Cmd + K` no Mac) para busca rápida no sistema.

## Módulo 02 — Atendimento ao Cliente

### 2.1 Recebendo Clientes — Walk-in (sem agendamento)

1. Ao receber o cliente, pergunte se ele já tem cadastro no sistema
2. Se **sim**, pesquise pelo nome ou telefone na barra de busca
3. Se **não**, ofereça realizar o cadastro (veja Módulo 03)
4. Verifique a agenda disponível para o profissional desejado
5. Se houver horário disponível, realize o agendamento
6. Se não houver, ofereça horário alternativo ou coloque na lista de espera

### 2.2 Recebendo Clientes com Agendamento

1. Solicite o nome ou telefone do cliente
2. Localize o agendamento na agenda
3. Confirme os dados: profissional, serviço, horário
4. Marque o cliente como **Chegou** (status "Confirmado")
5. Informe o profissional sobre a chegada do cliente
6. Se o cliente estiver atrasado, verifique o impacto nos horários seguintes

### 2.3 Telefone — Protocolo de Atendimento

**Script de atendimento:**

1. "Bom dia/Boa tarde! [Nome da Barbearia], com quem falo?"
2. Ouça atentamente a necessidade do cliente
3. Consulte a agenda disponível
4. Ofereça horários disponíveis
5. Confirme: nome, telefone, profissional, data, horário e serviço
6. Agradeça e finalize a ligação

**Regras importantes:**
- Sempre anote o nome do cliente que liga
- Confirme o telefone para contato
- Registre qual profissional foi solicitado
- Se o cliente ligar para cancelar, registre no sistema imediatamente

### 2.4 Identificação do Cliente

Sempre identifique o cliente antes de prosseguir com qualquer ação:

- **Por busca**: Digite nome ou telefone na barra de busca
- **Por lista**: Acesse a agenda e encontre o agendamento
- **Por comanda**: Se o cliente já estiver em atendimento, a comanda estará aberta

### 2.5 Uso do Kiosk (se disponível)

Caso a barbearia utilize o quiosque (kiosk) na recepção:

1. O cliente pode se cadastrar diretamente no kiosk
2. O cliente pode selecionar o profissional e serviço
3. O sistema gera automaticamente o agendamento
4. A recepção visualiza o novo agendamento na agenda
5. Não é necessário cadastrar novamente no sistema principal

## Módulo 03 — Cadastro de Clientes

### 3.1 Criando um Novo Cliente

1. Acesse **Clientes** no menu lateral
2. Clique em **Novo Cliente** (botão no canto superior direito)
3. Preencha os campos obrigatórios:
   - **Nome completo** (obrigatório)
   - **Telefone** (obrigatório) — formato: (XX) XXXXX-XXXX
   - **E-mail** (opcional mas recomendado)
4. Preencha campos opcionais:
   - Data de aniversário
   - CPF
   - Observações gerais
5. Clique em **Salvar**

### 3.2 Campos Obrigatórios vs. Opcionais

| Campo | Obrigatório | Observação |
|-------|-------------|------------|
| Nome completo | Sim | Nome como o cliente será identificado |
| Telefone | Sim | Principal forma de contato |
| E-mail | Não | Usado para envio de lembretes e promoções |
| Data de aniversário | Não | Permite enviar felicitações |
| CPF | Não | Pode ser necessário para notas fiscais |
| Observações | Não | Restrições, preferências, alergias |

### 3.3 Rastreamento de Aniversário

1. Ao cadastrar a data de aniversário, o sistema automaticamente:
   - Registra o aniversário do cliente
   - Pode enviar uma mensagem de felicitação (se configurado)
   - Exibe alerta no Dashboard no dia do aniversário
2. Para adicionar aniversário a um cliente existente:
   - Acesse o perfil do cliente
   - Clique em **Editar**
   - Adicione a data de aniversário
   - Salve as alterações

### 3.4 Histórico do Cliente

Para visualizar o histórico de um cliente:

1. Acesse **Clientes**
2. Busque pelo cliente desejado
3. Clique no nome para abrir o perfil
4. Acesse a aba **Histórico**
5. Você verá:
   - Todos os agendamentos passados
   - Serviços realizados
   - Valores pagos
   - Frequência de visitas
   - Última visita

### 3.5 Adicionando Notas ao Cliente

Notas são informações relevantes sobre o cliente que devem ser lembradas:

1. Abra o perfil do cliente
2. Localize o campo **Notas** ou **Observações**
3. Adicione a informação relevante
4. Salve

**Exemplos de notas úteis:**
- "Alérgico a certains produtos de barba"
- "Prefere cadeira específica"
- "Sempre atrasa 10 minutos"
- "Gosta de conversar sobre futebol"
- "Cliente fiel há 3 anos"

### 3.6 Preferências do Cliente

As preferências ficam registradas no perfil e são consultadas automaticamente:

1. Abra o perfil do cliente
2. Acesse **Preferências**
3. Registre:
   - Profissional preferido
   - Serviços favoritos
   - Horários preferidos
   - Observações especiais

### 3.7 Bloqueio de Clientes (se permitido)

> ⚠️ Esta funcionalidade pode estar restrita ao gestor. Verifique com seu supervisor antes de utilizar.

1. Acesse o perfil do cliente
2. Clique em **Mais opções**
3. Selecione **Bloquear Cliente**
4. Informe o motivo do bloqueio
5. Confirme a ação

> Clientes bloqueados não poderão realizar novos agendamentos pelo sistema.

### 3.8 Importação em Massa via CSV

Para importar múltiplos clientes de uma vez:

1. Acesse **Clientes**
2. Clique em **Importar** (ícone de seta para cima)
3. Baixe o template CSV clicando em **Baixar Template**
4. Preencha o template com os dados dos clientes
5. Faça upload do arquivo preenchido
6. O sistema validará os dados e mostrará possíveis erros
7. Confirme a importação

**Formato do template CSV:**

```
nome,telefone,email,aniversario,observacoes
João Silva,(11)99999-9999,joao@email.com,15/03/1990,
Maria Santos,(11)98888-8888,maria@email.com,,Cliente VIP
```

> ⚠️ Verifique se os números de telefone estão no formato correto antes de importar.

## Módulo 04 — Agenda

### 4.1 Criando Agendamentos

1. Acesse **Agenda** no menu lateral
2. Selecione a data desejada (clique no dia no calendário)
3. Clique em **Novo Agendamento** ou clique no horário desejado na grade
4. Preencha:
   - **Cliente**: busque pelo nome ou telefone
   - **Profissional**: selecione o profissional
   - **Serviço**: selecione o serviço desejado
   - **Data e Horário**: confirme data e horário
   - **Observações**: adicione notas se necessário
5. Clique em **Confirmar**

### 4.2 Editando Agendamentos

1. Localize o agendamento na agenda
2. Clique sobre o agendamento para abrir os detalhes
3. Clique em **Editar**
4. Altere os campos desejados
5. Clique em **Salvar Alterações**

> ⚠️ Ao alterar horário ou profissional, o sistema verificará conflitos automaticamente.

### 4.3 Cancelando Agendamentos

1. Localize o agendamento na agenda
2. Clique sobre o agendamento
3. Clique em **Cancelar**
4. Selecione o motivo do cancelamento:
   - Solicitação do cliente
   - Problema de agenda do profissional
   - Outro motivo
5. Confirme o cancelamento
6. O sistema notificará o profissional e, se configurado, o cliente

### 4.4 Gerenciando a Lista de Espera

A lista de espera é usada quando não há horário disponível:

1. Ao tentar agendar em horário lotado, o sistema oferecerá a opção de **Lista de Espera**
2. Selecione **Adicionar à Lista de Espera**
3. Informe os dados do cliente e o horário desejado
4. Quando um horário abrir, o sistema notificará automaticamente o cliente da lista
5. O primeiro da lista terá prioridade

**Gerenciando a lista:**
- Acesse **Agenda** → **Lista de Espera**
- Visualize os clientes na fila
- Remova clientes que já foram atendidos ou desistiram
- Reordene conforme necessidade

### 4.5 Confirmando Chegada do Cliente

1. Quando o cliente chegar, localize o agendamento na agenda
2. Clique no agendamento
3. Clique em **Confirmar Chegada** ou altere o status para **Confirmado**
4. O profissional será notificado que o cliente está pronto para atendimento

### 4.6 Status dos Agendamentos

| Status | Significado | Cor |
|--------|-------------|-----|
| Agendado | Cliente marcou, ainda não confirmou | Azul |
| Confirmado | Cliente confirmou presença ou chegou | Verde |
| Em Atendimento | Profissional está atendendo | Laranja |
| Concluído | Serviço finalizado | Cinza |
| Cancelado | Agendamento cancelado | Vermelho |
| Não Compareceu | Cliente não apareceu | Cinza escuro |

### 4.7 Bloqueios de Agenda

Bloqueios são períodos em que o profissional não está disponível:

1. Acesse **Agenda**
2. Selecione o profissional
3. Clique em **Novo Bloqueio**
4. Informe:
   - Motivo (almoço, feriado, folga, compromisso)
   - Data e horário de início
   - Data e horário de término
5. Confirme

> Bloqueios impedem novos agendamentos no período selecionado.

### 4.8 Detecção de Conflitos

O sistema verifica automaticamente conflitos ao criar ou editar agendamentos:

- **Conflito de horário**: Dois agendamentos no mesmo horário para o mesmo profissional
- **Conflito de buffer**: Tempo insuficiente entre dois agendamentos
- **Conflito com bloqueio**: Agendamento em período bloqueado

Se um conflito for detectado, o sistema exibirá alerta e sugestões de horários alternativos.

### 4.9 Agendamento Walk-in

Para clientes que chegam sem agendamento:

1. Verifique a agenda do profissional desejado
2. Se houver horário disponível, crie o agendamento normalmente
3. Marque como **Walk-in** ou **Sem Agendamento**
4. Processe o atendimento normalmente

## Módulo 05 — Reagendamento e Cancelamento

### 5.1 Fluxo de Reagendamento

1. Localize o agendamento original na agenda
2. Clique no agendamento
3. Clique em **Reagendar**
4. Selecione nova data e horário
5. Verifique disponibilidade do profissional
6. Confirme o reagendamento
7. O sistema notificará o cliente sobre a mudança

### 5.2 Fluxo de Cancelamento

1. Localize o agendamento
2. Clique no agendamento
3. Clique em **Cancelar**
4. Selecione o motivo
5. Confirme o cancelamento
6. Se aplicável, notifique o cliente

### 5.3 Cancelamento Iniciado pelo Cliente

Quando o cliente solicita cancelamento por telefone:

1. Identifique o cliente
2. Localize o agendamento
3. Confirme os dados com o cliente
4. Processe o cancelamento
5. Informe se há taxa de cancelamento (se aplicável)
6. Registre o motivo no sistema

### 5.4 Notificações do Sistema

O sistema envia notificações automaticamente:

| Evento | Notificação |
|--------|-------------|
| Novo agendamento | E-mail/SMS para o cliente |
| Reagendamento | E-mail/SMS para o cliente |
| Cancelamento | E-mail/SMS para o cliente |
| Lembrete (24h antes) | E-mail/SMS para o cliente |
| Lembrete (2h antes) | Push notification |

### 5.5 Impacto nas Comissões

- **Agendamento cancelado antes do serviço**: Sem impacto na comissão do profissional
- **Serviço concluído e depois cancelado**: A comissão pode ser revertida (verificar política da barbearia)
- **Reagendamento**: Não afeta comissão, pois o serviço será realizado em outro horário

> ⚠️ Em caso de dúvida sobre impacto na comissão, consulte o gestor.

## Módulo 06 — Comandas

### 6.1 Abrindo uma Comanda

Uma comanda é a ordem de serviço de cada cliente:

1. Ao iniciar o atendimento, acesse **Comandas**
2. Clique em **Nova Comanda**
3. Selecione o cliente
4. Selecione o profissional
5. Adicione os serviços
6. A comanda será criada com status **Aberta**

### 6.2 Adicionando Itens à Comanda

1. Na comanda aberta, clique em **Adicionar Item**
2. Selecione o tipo:
   - **Serviço**: selecione da lista de serviços
   - **Produto**: selecione da lista de produtos
3. Informe a quantidade (para produtos)
4. O item será adicionado à comanda com o preço definido no catálogo

### 6.3 Gerenciando o Status da Comanda

| Status | Significado |
|--------|-------------|
| Aberta | Comanda criada, atendimento em andamento |
| Em Andamento | Profissional está executando o serviço |
| Concluída | Todos os serviços foram realizados |
| Aguardando Pagamento | Serviço concluído, pendente de pagamento |
| Paga | Pagamento processado com sucesso |

### 6.4 Visualizando o Histórico de Comandas

1. Acesse **Comandas**
2. Use os filtros:
   - Por data
   - Por profissional
   - Por status
   - Por cliente
3. Visualize detalhes clicando em qualquer comanda

## Módulo 07 — Checkout/PDV

### 7.1 Montagem do Carrinho

1. Acesse **PDV** ou abra a comanda concluída
2. Itens já estarão adicionados (serviços e produtos)
3. Verifique se todos os itens estão corretos
4. Adicione itens adicionais se necessário

### 7.2 Aplicando Descontos

1. Na tela de checkout, clique em **Aplicar Desconto**
2. Selecione o tipo de desconto:
   - **Percentual**: informe a porcentagem (ex: 10%)
   - **Valor fixo**: informe o valor (ex: R$ 15,00)
3. Informe o motivo do desconto
4. Confirme

> ⚠️ Descontos acima de determinado valor podem exigir aprovação do gestor.

### 7.3 Créditos ChefClub

Se o cliente possuir créditos ChefClub:

1. Na tela de checkout, verifique se há créditos disponíveis
2. Selecione **Usar Créditos ChefClub**
3. Informe o valor a ser utilizado
4. O sistema deduzirá automaticamente o valor do total

### 7.4 Métodos de Pagamento

O SMG suporta diversos métodos de pagamento:

| Método | Descrição |
|--------|-----------|
| Dinheiro | Pagamento em espécie |
| Cartão de Crédito | Visão parcelada disponível |
| Cartão de Débito | Pagamento à vista |
| PIX | Transferência instantânea |
| Créditos ChefClub | Créditos do programa de fidelidade |
| Combinado | Mais de um método (ex: metade PIX, metade dinheiro) |

### 7.5 Processando o Pagamento

1. Selecione o método de pagamento
2. Para **Dinheiro**: informe o valor recebido (o sistema calcula o troco)
3. Para **Cartão**: selecione a bandeira e se será parcelado
4. Para **PIX**: aguarde a confirmação ou insira o comprovante
5. Para **Combinado**: adicione múltiplos métodos até cobrir o total
6. Clique em **Finalizar Pagamento**
7. Confirme a transação

### 7.6 Geração de Recibo

Após o pagamento processado:

1. O sistema gera automaticamente o recibo
2. Você pode:
   - **Imprimir** o recibo
   - **Enviar por e-mail** ao cliente
   - **Enviar por WhatsApp** (se disponível)
3. O recibo conterá: dados da barbearia, itens, valores, método de pagamento, data/hora

## Módulo 08 — Recebimentos

### 8.1 Processamento de Pagamentos

1. Acesse **Recebimentos** no menu lateral
2. Visualize todos os pagamentos do dia
3. Para processar um novo pagamento, acesse o PDV (Módulo 07)

### 8.2 Pagamentos com Múltiplos Métodos

Quando o cliente deseja dividir o pagamento:

1. Selecione o primeiro método (ex: PIX)
2. Informe o valor a ser pago via PIX
3. Clique em **Adicionar Outro Método**
4. Selecione o segundo método (ex: Dinheiro)
5. Informe o valor restante
6. O sistema validará se a soma dos valores é igual ao total
7. Processe o pagamento

### 8.3 Cálculo de Troco

Para pagamento em dinheiro:

1. Informe o valor recebido do cliente
2. O sistema calculará automaticamente o troco
3. Exiba o troco ao cliente
4. Confirme o pagamento

**Exemplo:**
- Total: R$ 75,00
- Valor recebido: R$ 100,00
- Troco: R$ 25,00

### 8.4 Emissão de Recibo

1. Após processar o pagamento, o recibo será gerado automaticamente
2. Você pode reimprimir ou enviar novamente a qualquer momento
3. Acesse **Recebimentos** → clique no pagamento → **Reemitir Recibo**

## Módulo 09 — Produtos

### 9.1 Visualizando o Catálogo de Produtos

1. Acesse **Produtos** no menu lateral
2. Visualize todos os produtos disponíveis
3. Use filtros para buscar por:
   - Nome
   - Categoria
   - Status (ativo/inativo)
   - Faixa de preço

### 9.2 Verificando o Estoque

1. Na lista de produtos, visualize a coluna **Estoque**
2. Produtos com estoque baixo aparecem com indicador amarelo
3. Produtos sem estoque aparecem com indicador vermelho
4. Clique em um produto para ver detalhes do estoque

### 9.3 Vendendo Produtos

Os produtos podem ser vendidos de duas formas:

**Via Comanda:**
1. Na comanda aberta, clique em **Adicionar Item**
2. Selecione **Produto**
3. Escolha o produto e quantidade
4. O item será adicionado à comanda

**Via PDV direto:**
1. Acesse **PDV**
2. Clique em **Adicionar Produto**
3. Busque e selecione o produto
4. Informe a quantidade
5. Processe o pagamento normalmente

### 9.4 Recomendação de Produtos

Use o histórico do cliente para recomendar produtos:

1. Ao atender um cliente frequente, consulte seu perfil
2. Verifique os serviços que ele costuma solicitar
3. Recomende produtos complementares
4. Exemplo: "Você costuma fazer a barba com navalha. Temos um creme pós-barba excelente."

## Módulo 10 — Caixa

### 10.1 Entendendo o Caixa

## Perguntas Frequentes (FAQ)

### 1. Como faço para cadastrar um cliente que nunca veio à barbearia?

Acesse **Clientes** → **Novo Cliente**, preencha nome e telefone (obrigatórios), adicione e-mail e outros dados se disponíveis, e clique em **Salvar**.

### 2. O cliente quer reagendar para um horário que não está disponível. O que faço?

Verifique horários alternativos na mesma data ou em datas próximas. Se não houver disponibilidade, ofereça a opção de entrar na **Lista de Espera**.

### 3. Como faço quando o cliente quer pagar com mais de um método?

No PDV, selecione o primeiro método e informe o valor. Clique em **Adicionar Outro Método**, selecione o segundo e informe o valor restante. A soma deve ser igual ao total.

### 4. O cliente reclamou de um cobrado. O que devo fazer?

Verifique os itens na comanda, confirme os preços no catálogo. Se houver erro, ajuste a comanda. Se o preço estiver correto, explique ao cliente. Em caso de dúvida, chame o gestor.

### 5. Como faço para ver o histórico de um cliente?

Acesse **Clientes** → busque o cliente → clique no nome → aba **Histórico**.

### 6. O sistema ficou lento. O que devo fazer?

Verifique sua conexão com a internet. Se estiver tudo normal, tente atualizar a página. Se persistir, crie um ticket de suporte.

### 7. Posso cancelar um agendamento sem o consentimento do cliente?

Apenas em casos excepcionais e com autorização do gestor. Em geral, cancelamentos devem ser solicitados pelo cliente.

### 8. Como funciona a Lista de Espera?

Quando um horário está lotado, você adiciona o cliente à lista. Quando um horário abrir (por cancelamento, por exemplo), o sistema notifica automaticamente o primeiro da fila.

### 9. Posso dar desconto sem autorização?

Descontos pequenos podem ser autorizados conforme política da barbearia. Descontos acima do limite estabelecido requerem aprovação do gestor. Consulte a política vigente.

### 10. O que acontece se o cliente não comparecer?

Após 15 minutos do horário agendado (configurável), você pode marcar como **Não Compareceu**. O sistema registrará no histórico do cliente.

### 11. Como faço para reimprimir um recibo?

Acesse **Recebimentos** → clique no pagamento desejado → **Reemitir Recibo**. Você pode imprimir ou enviar por e-mail.

### 12. Posso acessar os relatórios financeiros?

Não. Relatórios financeiros, despesas, reembolsos e conciliação são acessíveis apenas pelo perfil de Gestor. Sua função é visualizar o caixa diário e os recebimentos.

### 13. Como funciona o modo offline?

Quando sem internet, o sistema entra em modo automaticamente. Você pode visualizar agenda, criar agendamentos e cadastros. Ao reconectar, os dados são sincronizados automaticamente.

### 14. O cliente quer um serviço que não está no catálogo. O que faço?

Informe ao cliente que o serviço não está disponível no sistema e sugira um serviço similar. Não crie serviços novos — isso é função do gestor.

## Erros Mais Comuns

### 1. Não confirmar a chegada do cliente
**Problema:** O profissional não é notificado e o horário pode parecer vago.
**Solução:** Sempre marque o cliente como "Confirmado" ao chegar.

### 2. Esquecer de adicionar itens à comanda
**Problema:** O checkout fica incompleto e o profissional não recebe comissão.
**Solução:** Verifique todos os serviços realizados antes de processar o pagamento.

### 3. Processar pagamento sem verificar descontos pendentes
**Problema:** O cliente pode pagar a mais.
**Solução:** Revise os itens e descontos antes de finalizar.

### 4. Não notificar o profissional sobre cancelamentos
**Problema:** O profissional fica sabendo tarde demais e perde tempo.
**Solução:** Ao cancelar, verifique se o profissional foi notificado pelo sistema.

### 5. Cadastrar cliente sem telefone
**Problema:** Não é possível enviar lembretes ou contatar o cliente.
**Solução:** Sempre solicite o telefone, é campo obrigatório por boa prática.

### 6. Reagendar sem verificar conflitos
**Problema:** Dois agendamentos no mesmo horário.
**Solução:** O sistema alerta automaticamente. Sempre verifique antes de confirmar.

### 7. Processar checkout com método de pagamento errado
**Problema:** Divergência no caixa.
**Solução:** Confirme o método de pagamento com o cliente antes de processar.

### 8. Não usar o modo offline quando necessário
**Problema:** Perde produtividade sem necessidade.
**Solução:** Verifique se o sistema está funcionando. Se não, ative o modo offline manualmente.

### 9. Esquecer de aplicar o motivo do cancelamento
**Problema:** Dados incompletos para relatórios futuros.
**Solução:** Sempre preencha o motivo do cancelamento.

### 10. Não gerar recibo após pagamento
**Problema:** Cliente sem comprovante, problema em caso de disputa.
**Solução:** Sempre gere e entregue/envie o recibo após o pagamento.

## Fluxos Operacionais

### Fluxo 1: Recebendo um Cliente Walk-in

1. Receba o cliente com cordialidade
2. Pergunte se já tem cadastro
3. Se **não**, cadastre rapidamente (nome + telefone mínimo)
4. Pergunte qual profissional e serviço desejado
5. Consulte a agenda do profissional
6. Se houver horário disponível:
   - Crie o agendamento
   - Abra a comanda
   - Informe o profissional
7. Se não houver horário:
   - Ofereça horário alternativo
   - Ou adicione à lista de espera
8. Mantenha o cliente informado sobre o tempo de espera

### Fluxo 2: Processando uma Reserva por Telefone

1. Atenda com a saudação padrão
2. Ouça a necessidade do cliente
3. Pesquise o cliente no sistema (nome ou telefone)
4. Consulte a agenda para o profissional e data solicitados
5. Ofereça horários disponíveis
6. Confirme: nome, telefone, profissional, data, horário, serviço
7. Registre o agendamento no sistema
8. Informe que o lembrete será enviado automaticamente
9. Agradeça e finalize

### Fluxo 3: Atendendo uma Solicitação de Cancelamento

1. Identifique o cliente
2. Localize o agendamento
3. Confirme os dados do agendamento com o cliente
4. Pergunte o motivo do cancelamento
5. Informe se há política de cancelamento (taxa, prazo)
6. Registre o cancelamento no sistema com o motivo
7. Verifique se o profissional foi notificado
8. Ofereça reagendamento se aplicável
9. Confirme o cancelamento com o cliente

### Fluxo 4: Processando um Checkout

1. Abra a comanda do cliente
2. Verifique todos os itens (serviços + produtos)
3. Adicione itens faltantes se necessário
4. Revise os preços
5. Pergunte sobre descontos aplicáveis
6. Aplique desconto se houver
7. Informe o total ao cliente
8. Pergunte o método de pagamento
9. Processe o pagamento
10. Para dinheiro: calcule e entregue o troco
11. Gere e entregue/envie o recibo
12. Agradeça e despide o cliente

### Fluxo 5: Procedimentos de Fechamento

1. Verifique se há comandas abertas sem pagamento
2. Contate os clientes pendentes se necessário
3. Feche todas as comandas do dia
4. Acesse o caixa do dia
5. Confirme o total de recebimentos por método
6. Verifique divergências
7. Gere o relatório de fechamento
8. Envie o relatório ao gestor
9. Registre pendências e ocorrências
10. Faça logout do sistema

## Cenários Reais

### Cenário 1: Cliente Chegou Sem Agendamento

**Situação:** João chega à barbearia sem agendamento às 14h.
**Ação:**
1. Receba com cordialidade
2. Consulte a agenda dos profissionais disponíveis
3. Se houver horário, crie o agendamento e abra a comanda
4. Se não houver, ofereça horário alternativo ou lista de espera
5. Cadastre João se for a primeira visita

### Cenário 2: Agendamento Duplo Detectado

**Situação:** Ao criar um agendamento, o sistema alerta conflito com outro.
**Ação:**
1. Verifique os dois agendamentos conflitantes
2. Identifique qual foi criado primeiro
3. Consulte o profissional sobre qual manter
4. Reagende o mais recente para outro horário
5. Notifique o cliente reagendado
6. Documente a ocorrência

### Cenário 3: Cliente Quer Cancelar em Última Hora

**Situação:** Liga 30 minutos antes do horário pedindo cancelamento.
**Ação:**
1. Identifique o cliente e o agendamento
2. Registre o cancelamento no sistema
3. Informe ao profissional imediatamente
4. Verifique se há alguém na lista de espera para ocupar o horário
5. Registre o motivo do cancelamento

### Cenário 4: Método de Pagamento Recusado

**Situação:** Cartão de crédito do cliente não foi aprovado.
**Ação:**
1. Informe ao cliente de forma discreta
2. Ofereça outro método de pagamento (PIX, dinheiro, outro cartão)
3. Se não tiver outro método, oriente sobre como resolver (contatar banco)
4. NÃO cancele o serviço — mantenha a comanda aberta
5. Consulte o gestor se necessário

### Cenário 5: Cliente Disputa o Preço Cobrado

**Situação:** Cliente acha que o valor está errado.
**Ação:**
1. Mantenha a calma e ouça o cliente
2. Verifique os itens na comanda
3. Consulte os preços no catálogo de serviços
4. Se houver erro, corrija imediatamente
5. Se o preço estiver correto, explique detalhadamente
6. Se o cliente insistir, chame o gestor

### Cenário 6: Sistema Está Lento

**Situação:** O SMG está demorando para responder.
**Ação:**
1. Verifique sua conexão com a internet
2. Feche abas desnecessárias no navegador
3. Atualize a página (F5 ou Ctrl+R)
4. Se persistir, tente outro navegador
5. Se continuar, crie um ticket de suporte
6. Enquanto isso, anote os dados manualmente para registrar depois

### Cenário 7: Ligação Telefônica em Horário de Pico

**Situação:** Telefone toca enquanto há fila de clientes na recepção.
**Ação:**
1. Atenda rapidamente com a saudação padrão
2. Seja breve: "Bom dia! [Barbearia], com quem falo?"
3. Se for agendamento, agenda rápido e confirma dados por SMS
4. Se for dúvida complexa, peça para ligar em outro horário
5. Atenda o próximo cliente presencial rapidamente

### Cenário 8: Cliente Apresenta Cupom de Desconto

**Situação:** Cliente entrega um cupom de promoção.
**Ação:**
1. Verifique a validade do cupom (data, regras)
2. Confirme com o gestor se o cupom é válido
3. Se válido, aplique o desconto no checkout
4. Registre o código do cupom na transação
5. Se inválido, informe o cliente educadamente

### Cenário 9: Cliente Quer Profissional Que Está Ocupado

**Situação:** Cliente prefere o barbeiro Carlos, mas ele está atendendo.
**Ação:**
1. Informe o tempo estimado de espera
2. Ofira horário alternativo (logo após o término)
3. Sugira outro profissional com disponibilidade
4. Se o cliente preferir esperar, adicione à lista de espera
5. Quando Carlos estiver livre, notifique o cliente

### Cenário 10: Cliente Quer Dividir a Conta

**Situação:** Cliente quer pagar metade no PIX e metade em dinheiro.
**Ação:**
1. No checkout, selecione **PIX** e informe metade do valor
2. Clique em **Adicionar Outro Método**
3. Selecione **Dinheiro** e informe a outra metade
4. Verifique se a soma é igual ao total
5. Processe o pagamento
6. Gere o recibo com ambos os métodos

### Cenário 11: Cliente Chegou com Criança

**Situation:** Cliente trouxe criança que precisa de corte infantil.
**Ação:**
1. Verifique se o serviço infantil está disponível no catálogo
2. Se sim, agende para o profissional que realiza o serviço
3. Se não, informe que o serviço não está disponível
4. Não crie serviços novos — consulte o gestor

### Cenário 12: Sistema Fica Offline no Meio do Atendimento

**Situação:** Conexão cai durante o checkout.
**Ação:**
1. Notifique o cliente sobre a situação
2. Verifique se o modo offline está ativo
3. Se estiver, processe o checkout normalmente
4. Anote os dados manualmente se necessário
5. Quando a conexão voltar, sincronize os dados
6. Confirme que tudo foi registrado corretamente
