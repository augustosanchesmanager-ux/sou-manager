## Objetivo do Treinamento

Ao final deste treinamento, o barbeiro será capaz de:

1. Realizar login, configurar o perfil e navegar pela interface com autonomia.
2. Visualizar e gerenciar a própria agenda de atendimentos.
3. Abrir, gerenciar e fechar comandas corretamente.
4. Executar o fluxo completo de atendimento, desde o recebimento do cliente até a finalização do serviço.
5. Utilizar o Checkout/PDV para cobrar serviços e produtos.
6. Compreender o cálculo de comissão e acompanhar o próprio histórico.
7. Realizar o fechamento individual de caixa ao final do dia.
8. Utilizar notificações, suporte e modo offline quando necessário.

---

## Pré-requisitos

- Conta criada e aprovada pelo gerente/manager do estabelecimento.
- Credenciais de acesso (e-mail e senha) recebidas via e-mail ou presencialmente.
- Conhecimento básico de uso de smartphone ou computador (navegador web).
- Acesso estável à internet (para sincronização inicial).
- Dispositivo com navegador atualizado (Chrome, Edge, Safari ou Firefox).

## Módulo 01 — Primeiro Acesso

### 1.1 Login

1. Acesse o sistema pelo endereço fornecido pelo gerente.
2. Na tela de login, insira o **e-mail** cadastrado.
3. Insira a **senha** fornecida.
4. Clique em **Entrar**.

> **Nota:** Se a conta ainda não foi ativada pelo gerente, o acesso será bloqueado. Nesse caso, entre em contato com a gestão.

### 1.2 Alteração de Senha

Ao realizar o primeiro login, o sistema solicitará a alteração da senha:

1. Digite a senha atual (fornecida pelo gerente).
2. Digite a nova senha (mínimo de 8 caracteres, recomendado: letras + números + caractere especial).
3. Confirme a nova senha.
4. Clique em **Salvar**.

> **Regra de segurança:** Nunca compartilhe sua senha. O sistema registra todos os acessos.

### 1.3 Configuração do Perfil

Após o primeiro acesso, complete as informações do perfil:

1. Acesse **Menu → Meu Perfil**.
2. Adicione uma **foto de avatar** (opcional, mas recomendado para identificação visual).
3. Preencha o **telefone de contato**.
4. Verifique se o **nome completo** e o **e-mail** estão corretos.
5. Clique em **Salvar Alterações**.

### 1.4 Visão Geral do Dashboard

O Dashboard é a primeira tela exibida após o login. Nele você encontra:

- **KPIs do dia:** Receita do dia, agendamentos realizados, novos clientes.
- **Próximos atendimentos:** Lista dos agendamentos pendentes.
- **Resumo da semana:** Visão geral de performance.

> **Nota:** O Dashboard do barbeiro mostra apenas seus próprios dados. Dados gerais do estabelecimento ficam disponíveis apenas para gerentes.

### 1.5 Navegação pela Interface

- **Menu lateral (sidebar):** Acesse as funcionalidades (Agenda, Comandas, Notificações, etc.).
- **Cabeçalho:** Notificações, perfil e logout.
- **Atalhos:** Alguns atalhos de teclado estão disponíveis (verIFIque no rodapé da tela).

### 1.6 Tema Dark/Light

O sistema oferece dois temas visuais:

1. Acesse **Menu → Meu Perfil**.
2. Na seção **Aparência**, selecione o tema desejado.
3. A mudança é aplicada imediatamente.

> **Dica:** O tema escuro é recomendado para ambientes com pouca luminosidade.

## Módulo 02 — Agenda

### 2.1 Visualizando sua Agenda

1. Acesse **Menu → Agenda**.
2. A agenda mostra apenas os agendamentos vinculados ao seu usuário.
3. Visualize por **dia**, **semana** ou **mês** usando os botões de alternância no topo.

### 2.2 Status dos Agendamentos

| Cor | Status | Significado |
|-----|--------|-------------|
| Azul | Agendado | Cliente confirmou presença |
| Amarelo | Confirmado | Cliente confirmou (lembrete enviado) |
| Verde | Em andamento | Atendimento em curso |
| Cinza | Concluído | Serviço finalizado |
| Vermelho | Cancelado | Agendamento cancelado |

### 2.3 Confirmação de Chegada do Cliente

Quando o cliente chega ao estabelecimento:

1. Localize o agendamento na agenda.
2. Clique no agendamento e selecione **Confirmar Presença**.
3. O status mudará para **Em andamento**.
4. O sistema registrará o horário real de início do atendimento.

### 2.4 Finalizando um Agendamento

Após concluir o atendimento:

1. Clique no agendamento.
2. Selecione **Finalizar Atendimento**.
3. Preencha os detalhes (serviço executado, produtos utilizados).
4. Confirme a finalização.

> **Importante:** Um agendamento só pode ser finalizado após o registro completo do serviço.

### 2.5 Bloqueios de Agenda

O sistema pode exibir bloqueios na agenda:

- **Almoço:** Período de intervalo para refeição.
- **Pausa:** Intervalo curto entre atendimentos.
- **Indisponibilidade:** Bloqueios manuais do gerente.

> **Regra:** Bloqueios não podem ser removidos pelo barbeiro. Em caso de necessidade, solicite ao gerente.

### 2.6 Drag and Drop

O sistema permite reorganizar agendamentos arrastando e soltando:

1. Pressione e segure sobre o agendamento.
2. Arraste para o novo horário desejado.
3. Solte para confirmar a movimentação.

> **Restrição:** O sistema detectará conflitos automaticamente. Não será possível movimentar para um horário já ocupado.

### 2.7 Atendimentos Sem Agendamento (Walk-in)

Para clientes que chegam sem agendamento:

1. Na agenda, clique em **+ Novo Agendamento**.
2. Selecione o horário disponível.
3. Busque o cliente existente ou cadastre um novo rapidamente.
4. Confirme o agendamento.
5. Proceda com o atendimento normalmente.

## Módulo 03 — Comandas

### 3.1 Abrindo uma Comanda

1. Acesse **Menu → Comandas**.
2. Clique em **Nova Comanda**.
3. Selecione o cliente (busque pelo nome, telefone ou CPF).
4. Adicione os serviços que serão executados.
5. Confirme a abertura.

> **Regra:** Uma comanda deve estar aberta para registrar serviços e produtos vinculados ao atendimento.

### 3.2 Adicionando Serviços

1. Na comanda aberta, clique em **+ Adicionar Serviço**.
2. Busque o serviço pelo nome.
3. Selecione a quantidade (se aplicável).
4. Confirme a adição.

### 3.3 Adicionando Produtos

1. Na comanda aberta, clique em **+ Adicionar Produto**.
2. Busque o produto pelo nome.
3. Informe a quantidade.
4. Confirme a adição.

> **Nota:** Produtos são itens de venda (shampoo, pomada, etc.) que impactam o financeiro da comanda.

### 3.4 Status das Comandas

| Status | Descrição |
|--------|-----------|
| Aberta | Comanda ativa, aguardando finalização |
| Paga | Comanda encerrada com pagamento confirmado |
| Bloqueada | Comanda com pendência (aguardando ação do gerente) |
| Cancelada | Comanda cancelada (não gera efeito financeiro) |

### 3.5 Histórico de Comandas

1. Acesse **Menu → Comandas → Histórico**.
2. Filtre por **período**, **cliente** ou **status**.
3. Visualize detalhes clicando em uma comanda.

### 3.6 Efeito Financeiro vs Sem Efeito Financeiro

- **Com efeito financeiro:** Comandas pagas ou que geram transação no sistema.
- **Sem efeito financeiro:** Comandas canceladas ou com status de "bloqueada".

> **Regra:** Apenas comandas com efeito financeiro são contabilizadas no relatório de comissão.

## Módulo 04 — Atendimento

### 4.1 Recebendo o Cliente

1. Verifique a agenda do dia para os próximos atendimentos.
2. Quando o cliente chegar, confirme sua identidade.
3. Registre a **chegada** na agenda (status: Em andamento).
4. Inicie a comanda correspondente (se ainda não estiver aberta).

### 4.2 Confirmação do Serviço Agendado

1. Ao abrir a comanda, o sistema exibirá o serviço agendado.
2. Confirme com o cliente se o serviço será realizado conforme o agendamento.
3. Caso haja alterações, ajuste os itens na comanda antes de prosseguir.

### 4.3 Registro da Execução do Serviço

1. Durante o atendimento, mantenha a comanda aberta.
2. Ao finalizar cada etapa, registre na comanda.
3. Ao concluir, selecione **Finalizar Serviço**.

### 4.4 Execução Multi-participante

O sistema permite registro de múltiplos participantes em um único atendimento:

| Papel | Descrição |
|-------|-----------|
| **Primário** | Barbeiro responsável principal pelo serviço |
| **Assistente** | Barbeiro que auxilia no serviço (ex: lavagem) |
| **Co-executor** | Barbeiro que executa parte do serviço em conjunto |

Para registrar execução multi-participante:

1. Ao adicionar o serviço na comanda, clique em **Definir Participantes**.
2. Selecione o papel de cada barbeiro envolvido.
3. A comissão será dividida conforme as regras configuradas pelo gerente.

### 4.5 Registro de Venda de Produtos

Durante o atendimento, o cliente pode solicitar a compra de produtos:

1. Na comanda aberta, clique em **+ Adicionar Produto**.
2. Busque e selecione o produto.
3. Informe a quantidade.
4. Confirme a adição.

> **Importante:** Registre todos os produtos vendidos durante o atendimento. Isso afeta o cálculo de comissão e o controle de estoque.

### 4.6 Finalização do Atendimento

1. Verifique se todos os serviços e produtos foram registrados.
2. Confirme com o cliente se está tudo correto.
3. Clique em **Finalizar Atendimento**.
4. O sistema direcionará para o Checkout/PDV.

## Módulo 05 — Checkout/PDV

### 5.1 Montagem do Carrinho

Ao acessar o Checkout, o sistema exibirá os itens da comanda:

- **Serviços:** Itens de execução registrados.
- **Produtos:** Itens de venda adicionados.

1. Revise os itens do carrinho.
2. Verifique se os valores estão corretos.
3. Adicione ou remova itens se necessário (antes do fechamento).

### 5.2 Aplicação de Descontos

Se você tiver permissão para aplicar descontos:

1. Clique em **Aplicar Desconto**.
2. Selecione o tipo: **Percentual** ou **Valor Fixo**.
3. Informe o valor do desconto.
4. Confirme a aplicação.

> **Restrição:** Descontos acima do limite configurado requerem aprovação do gerente.

### 5.3 Aplicação de Créditos ChefClub

Se o cliente possuir créditos ChefClub:

1. Clique em **Aplicar Crédito ChefClub**.
2. O sistema exibirá o saldo disponível do cliente.
3. Selecione o valor a ser utilizado.
4. Confirme a aplicação.

> **Nota:** Créditos ChefClub são descontados do valor total antes da seleção da forma de pagamento.

### 5.4 Seleção da Forma de Pagamento

1. Após aplicar descontos e créditos, selecione a **Forma de Pagamento**:
   - Dinheiro
   - Cartão de Crédito
   - Cartão de Débito
   - PIX
   - Transferência Bancária
   - Crédito ChefClub (se houver saldo restante)
2. Informe os dados conforme a forma selecionada.

### 5.5 Processamento do Pagamento

1. Confirme o valor total a ser cobrado.
2. Clique em **Confirmar Pagamento**.
3. O sistema registrará a transação e gerará o comprovante.

> **Regra:** Pagamentos com cartão de crédito podem parcelar conforme regras do estabelecimento.

### 5.6 Geração de Comprovante

Após o pagamento:

1. O sistema exibirá o comprovante na tela.
2. Opções disponíveis:
   - **Imprimir** comprovante.
   - **Enviar por e-mail** ao cliente.
   - **Enviar por WhatsApp** ao cliente.
3. O comprovante também fica disponível no histórico da comanda.

### 5.7 Ações Pós-Checkout

Após finalizar o pagamento:

- A comanda será marcada como **Paga**.
- O agendamento será marcado como **Concluído**.
- A comissão será calculada automaticamente.
- O estoque dos produtos vendidos será atualizado.
- Uma notificação de confirmação será enviada ao cliente (se configurado).

## Módulo 06 — Comissão

### 6.1 Entendendo o Cálculo de Comissão

A comissão é calculada com base nos serviços executados e produtos vendidos:

- **Serviços:** Percentual sobre o valor do serviço.
- **Produtos:** Percentual sobre o valor do produto (quando configurado).

> **Nota:** A taxa de comissão é configurada pelo gerente e pode variar por tipo de serviço.

### 6.2 Execução Solo vs Compartilhada

| Tipo | Descrição | Cálculo |
|------|-----------|---------|
| **Solo** | Você executou o serviço sozinho | 100% da comissão configurada |
| **Primário** | Você liderou o serviço com assistentes | Comissão majorada (conforme regra) |
| **Assistente** | Você auxiliou em um serviço | Comissão parcial (conforme regra) |
| **Co-executor** | Execução em conjunto igualitária | Comissão dividida igualmente |

### 6.3 Configuração da Taxa de Comissão

> **Nota:** A taxa de comissão é definida pelo gerente e **não pode ser alterada pelo barbeiro**. Este módulo é apenas para compreensão.

- Acesse **Menu → Minha Comissão → Configurações**.
- Visualize a taxa atual configurada para cada tipo de serviço.

### 6.4 Histórico de Comissão

1. Acesse **Menu → Minha Comissão**.
2. Filtre por **período** (semana, mês, período personalizado).
3. Visualize os detalhes:
   - Data do atendimento
   - Cliente atendido
   - Serviço executado
   - Valor do serviço
   - Percentual de comissão
   - Valor da comissão

### 6.5 Impacto da Seleção de Fonte de Dados

O sistema permite visualizar comissões com base em duas fontes:

- **Data do Pagamento:** Comissão contabilizada na data em que o pagamento foi registrado.
- **Data do Atendimento:** Comissão contabilizada na data em que o serviço foi executado.

> **Dica:** Para fins de conferência, utilize sempre a mesma fonte de dados.

## Módulo 07 — Fechamento Individual

### 7.1 Resumo Diário Individual

Ao final do dia de trabalho:

1. Acesse **Menu → Fechamento Individual**.
2. O sistema exibirá um resumo de suas operações do dia:
   - Total de atendimentos realizados
   - Total de produtos vendidos
   - Total em comissão
   - Formas de pagamento recebidas

### 7.2 Revisão das Transações

1. Revise cada transação listada no resumo.
2. Verifique se há alguma transação pendente ou com erro.
3. Em caso de dúvida, clique nos detalhes de cada transação.

### 7.3 Fechamento do Caixa Individual

1. Após revisar todas as transações, clique em **Fechar Caixa**.
2. Confirme o fechamento.
3. O sistema gerará o relatório de fechamento individual.

> **Regra:** O fechamento individual é diferente do fechamento de caixa geral (feito pelo gerente).

### 7.4 Conferência do Caixa Individual

1. Compare o valor registrado no sistema com o valor em mãos (se aplicável).
2. Registre o valor conferido.
3. Em caso de divergência, registre na observação e notifique o gerente.

## Módulo 10 — Modo Offline

### 10.1 Quando o Modo Offline se Ativa

O modo offline é ativado automaticamente quando:

- A conexão com a internet é perdida.
- O servidor do sistema está indisponível.

> **Nota:** O ícone de conexão mudará para indicar o status offline.

### 10.2 O que Funciona Offline

| Funcionalidade | Status |
|----------------|--------|
| Visualizar agenda do dia | Disponível |
| Registrar atendimentos | Disponível (salvo localmente) |
| Abrir comandas | Disponível (salvo localmente) |
| Processar pagamentos | Limitado (verifique configurações) |
| Acessar dados de clientes | Última sincronização disponível |
| Notificações | Não disponível |
| Relatórios | Não disponível |

### 10.3 Processo de Sincronização

Quando a conexão é restaurada:

1. O sistema detectará automaticamente a conexão.
2. Os dados salvos localmente serão sincronizados com o servidor.
3. Um indicador mostrará o progresso da sincronização.
4. Após a sincronização completa, o sistema voltará ao modo online.

> **Importante:** Aguarde a sincronização completa antes de realizar novas operações.

### 10.4 Resolução de Conflitos de Sincronização

Em caso de conflitos (mesmo registro alterado offline e online):

1. O sistema exibirá um aviso de conflito.
2. Selecione a versão correta dos dados.
3. Confirme a resolução.

> **Dica:** Em caso de dúvida, entre em contato com o gerente antes de resolver o conflito.

## Perguntas Frequentes (FAQ)

### 1. Esqueci minha senha. O que fazer?

Na tela de login, clique em **Esqueci minha senha**. Um e-mail de redefinição será enviado ao endereço cadastrado. Caso não receba o e-mail, entre em contato com o gerente.

### 2. Não consigo acessar a agenda de outros barbeiros. Por quê?

O sistema é configurado para que cada barbeiro visualize apenas sua própria agenda. A agenda completa fica disponível apenas para o gerente.

### 3. Como faço para cancelar uma comanda?

Comandas só podem ser canceladas pelo gerente. Em caso de necessidade, solicite o cancelamento ao gerente via ticket de suporte ou presencialmente.

### 4. O que acontece se eu esquecer de registrar um produto vendido?

O estoque não será atualizado e o valor do produto não será cobrado. Registre o produto assim que perceber o esquecimento. Se o cliente já saiu, notifique o gerente.

### 5. Posso alterar minha taxa de comissão?

Não. A taxa de comissão é configurada exclusivamente pelo gerente. Em caso de dúvidas, acesse **Minha Comissão** para visualizar a taxa atual.

### 6. Como funciona a comissão quando dois barbeiros trabalham no mesmo serviço?

O sistema registra os participantes (primário, assistente, co-executor) e distribui a comissão conforme as regras configuradas pelo gerente.

### 7. O que fazer se o sistema ficar offline durante um atendimento?

O modo offline será ativado automaticamente. Continue o atendimento normalmente. Os dados serão sincronizados quando a conexão for restaurada.

### 8. Como envio o comprovante para o cliente?

Após o pagamento, selecione a opção de enviar por **e-mail** ou **WhatsApp** na tela de comprovante.

### 9. Posso descontar do valor total sem autorização do gerente?

Depende da permissão configurada. Descontos acima do limite estabelecido requerem aprovação do gerente.

### 10. Como acesso o relatório de comissão do mês?

Acesse **Menu → Minha Comissão**, selecione o período desejado (mês) e visualize o resumo detalhado.

### 11. O que significam os diferentes status da comanda?

- **Aberta:** Em uso, aguardando finalização.
- **Paga:** Finalizada com pagamento confirmado.
- **Bloqueada:** Pendente de ação (gerente).
- **Cancelada:** Sem efeito financeiro.

### 12. Posso reagendar um cliente pelo sistema?

Sim. Acesse o agendamento na agenda, clique em **Reagendar** e selecione a nova data/horário.

## Erros Mais Comuns

### 1. Não registrar a chegada do cliente

**Consequência:** O atendimento não é contabilizado corretamente e a comissão pode não ser calculada.

**Como evitar:** Sempre confirme a chegada do cliente antes de iniciar o atendimento.

### 2. Finalizar o atendimento antes de registrar todos os itens

**Consequência:** Serviços ou produtos podem ficar fora da comanda, gerando divergência financeira.

**Como evitar:** Revise todos os itens antes de finalizar. Use a checklist visual da comanda.

### 3. Não aplicar o desconto no momento certo

**Consequência:** O cliente pode ser cobrado incorretamente.

**Como evitar:** Aplique descontos e créditos antes de selecionar a forma de pagamento.

### 4. Fechar a comanda sem gerar comprovante

**Consequência:** O cliente não recebe comprovante e pode questionar o pagamento.

**Como evitar:** Sempre gere e envie o comprovante após o pagamento.

### 5. Não registrar execução multi-participante

**Consequência:** A comissão será calculada apenas para o barbeiro primário, prejudicando o assistente/co-executor.

**Como evitar:** Registre todos os participantes ao adicionar o serviço na comanda.

### 6. Ignorar o modo offline

**Consequência:** Dados podem ser perdidos se o sistema estiver offline e o barbeiro tentar operar normalmente.

**Como evitar:** Verifique o status da conexão antes de operar. Em caso de dúvidas, aguarde a sincronização.

### 7. Não conferir o fechamento individual

**Consequência:** Divergências entre o valor registrado e o valor real podem passar despercebidas.

**Como evitar:** Sempre confira o fechamento antes de finalizar o dia.

### 8. Acessar funcionalidades restritas sem necessidade

**Consequência:** Tentativas de acesso bloqueado geram frustração e perda de tempo.

**Como evitar:** Familiarize-se com as funcionalidades disponíveis para o seu perfil. Em caso de necessidade de acesso adicional, solicite ao gerente.

## Procedimentos Obrigatórios

### Procedimentos Diários

#### Antes de Abrir (Início do Dia)

1. Realizar login e verificar o dashboard.
2. Conferir a agenda do dia (horários, clientes, serviços).
3. Verificar se há notificações pendentes.
4. Confirmar que o sistema está online e sincronizado.

#### Durante o Dia

1. Confirmar a chegada de cada cliente no horário agendado.
2. Abrir comanda para cada atendimento.
3. Registrar todos os serviços executados e produtos vendidos.
4. Aplicar descontos e créditos (se houver) antes do pagamento.
5. Gerar e enviar comprovante para cada pagamento.
6. Verificar o status da conexão periodicamente.

#### Antes de Fechar (Final do Dia)

1. Finalizar todas as comandas abertas.
2. Realizar o fechamento individual.
3. Conferir o valor registrado com o valor em mãos.
4. Registrar divergências (se houver) e notificar o gerente.
5. Realizar logout do sistema.

### Procedimentos de Emergência

#### Sistema Fora do Ar

1. Não entre em pânico — o modo offline deve ser ativado automaticamente.
2. Continue os atendimentos usando o modo offline.
3. Registre todos os dados localmente.
4. Ao restaurar a conexão, aguarde a sincronização completa.
5. Verifique se todos os dados foram sincronizados corretamente.

#### Divergência no Caixa

1. Registre a divergência na observação do fechamento.
2. Notifique o gerente imediatamente.
3. Não encerre o dia até resolver ou documentar a divergência.

#### Cliente Insatisfeito com Cobrança

1. Mantenha a calma e escute o cliente.
2. Verifique os itens da comanda no sistema.
3. Se houver erro, notifique o gerente para correção.
4. Não realize ajustes financeiros sem autorização.

## Boas Práticas

### Conduta Profissional

1. **Pontualidade:** Chegue antes do horário de início para preparar seus materiais.
2. **Apresentação:** Mantenha aparência adequada para o atendimento ao público.
3. **Respeito:** Trate todos os clientes com cordialidade e profissionalismo.
4. **Sigilo:** Não compartilhe informações pessoais de clientes com terceiros.
5. **Comunicação:** Mantenha o gerente informado sobre ocorrências durante o dia.

### Higiene de Dados

1. **Dados corretos:** Sempre verifique as informações do cliente antes de confirmar.
2. **Registro completo:** Registre todos os serviços e produtos, sem exceções.
3. **Sem duplicatas:** Verifique se já existe uma comanda aberta antes de criar uma nova.
4. **Backup de comprovantes:** Sempre envie o comprovante para o cliente (e-mail ou WhatsApp).

### Gestão de Tempo

1. **Respeite os horários:** Inicie e finalize os atendimentos conforme a agenda.
2. **Intervalos:** Utilize os intervalos configurados no sistema para descanso.
3. **Antecipação:** Verifique a agenda com antecedência para se preparar.
4. **Flexibilidade:** Esteja preparado para lidar com imprevistos (atrasos, walk-ins).

## Cenários Reais

### Cenário 1: Cliente Chegou Atrasado

**Situação:** O cliente chegou 30 minutos após o horário agendado.

**Procedimento:**
1. Verifique se há outro agendamento próximo.
2. Se houver conflito, informe o cliente sobre a possibilidade de reagendamento.
3. Se for possível atender, registre a chegada normalmente.
4. Ajuste o horário de início do atendimento para o horário real.
5. Informe o cliente sobre possíveis ajustes na duração do serviço.

### Cenário 2: Cliente Deseja Reagendar

**Situação:** O cliente ligou pedindo para reagendar o atendimento do dia.

**Procedimento:**
1. Acesse o agendamento na agenda.
2. Clique em **Reagendar**.
3. Consulte horários disponíveis em conjunto com o cliente.
4. Selecione o novo horário e confirme.
5. Envie confirmação do reagendamento ao cliente.

### Cenário 3: Pagamento Falhou

**Situação:** O cartão de crédito do cliente foi recusado.

**Procedimento:**
1. Informe o cliente sobre a falha de forma discreta.
2. Verifique se há outra forma de pagamento disponível.
3. Se necessário, cancele a transação atual e inicie uma nova com a forma alternativa.
4. Se não for possível resolver, notifique o gerente.

### Cenário 4: Cliente Deseja Adicionar um Serviço Durante o Atendimento

**Situação:** Durante o corte, o cliente solicitou um barba adicional.

**Procedimento:**
1. Verifique se há tempo disponível na agenda.
2. Adicione o serviço na comanda aberta.
3. Atualize o valor total da comanda.
4. Informe o cliente sobre a alteração no valor.
5. Prossiga com o atendimento.

### Cenário 5: Esqueceu de Registrar uma Venda de Produto

**Situação:** O cliente comprou um shampoo, mas o barbeiro esqueceu de registrar na comanda.

**Procedimento:**
1. Se a comanda ainda estiver aberta, adicione o produto imediatamente.
2. Se a comanda já foi fechada, notifique o gerente para correção.
3. Verifique se o estoque precisa ser ajustado manualmente.
4. Documente o ocorrido para registro.

### Cenário 6: Comanda com Erro de Cobrança

**Situação:** O cliente identificou que o valor cobrado está incorreto.

**Procedimento:**
1. Verifique os itens da comanda no sistema.
2. Se houver erro, notifique o gerente imediatamente.
3. Não realize ajustes financeiros sem autorização.
4. Aguarde a correção do gerente antes de prosseguir.
5. Documente o ocorrido.

### Cenário 7: Cliente Contestando um Cobrança

**Situação:** O cliente afirma que já pagou, mas o sistema mostra pendente.

**Procedimento:**
1. Verifique o histórico de transações da comanda.
2. Confirme se o pagamento foi registrado no sistema.
3. Se não foi registrado, verifique se há comprovante em mãos do cliente.
4. Notifique o gerente para investigação.
5. Não cancele a comanda sem autorização.

### Cenário 8: Sistema Fica Offline Durante o Atendimento

**Situação:** A internet caiu durante a execução do serviço.

**Procedimento:**
1. Verifique se o modo offline foi ativado automaticamente.
2. Continue o atendimento normalmente.
3. Registre os dados localmente (o sistema salva automaticamente).
4. Ao restaurar a conexão, aguarde a sincronização completa.
5. Verifique se todos os dados foram sincronizados corretamente.

### Cenário 9: Cliente Solicita Nota Fiscal

**Situação:** O cliente precisa de nota fiscal para fins de reembolso.

**Procedimento:**
1. Informe que a nota fiscal é emitida pelo estabelecimento.
2. Notifique o gerente sobre a solicitação.
3. Forneça os dados do cliente ao gerente para emissão.
4. Envie o comprovante ao cliente enquanto a nota não é emitida.

### Cenário 10: Múltiplos Clientes Chegam ao Mesmo Tempo

**Situação:** Dois clientes agendados para horários próximos chegam simultaneamente.

**Procedimento:**
1. Atenda o cliente com o horário mais antigo primeiro.
2. Informe ao segundo cliente sobre a espera estimada.
3. Verifique se há outro barbeiro disponível para auxiliar.
4. Registre a chegada de ambos na agenda.
5. Gerencie o tempo para minimizar a espera.
