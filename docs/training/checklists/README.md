# Checklists Operacionais — SMG

> Guias práticos para garantir operação segura e eficiente no Sou.Manager.

---

## Como Usar os Checklists

Cada checklist é uma **ferramenta de acompanhamento** para rotinas específicas do barbeiro. Eles servem para:

- **Padronizar processos** — Todos os profissionais seguem o mesmo fluxo
- **Reduzir erros** — Nenhuma etapa é esquecida
- **Facilitar treinamento** — Novos colaboradores aprendem rápido com etapas claras
- **Gerar histórico** — Registros de conclusão para auditoria

**Regras de uso:**

1. Execute os itens **na ordem apresentada**
2. Marque cada item somente após **confirmar** que está correto
3. Em caso de dúvida, **não marque** — registre no campo de observações
4. Checklists diários devem ser concluídos **antes do fim do expediente**
5. Checklists semanais/mensais devem ser arquivados na pasta de controle

## Checklist Diário — Abertura

### Barbeiro

- [ ] Login no sistema com credenciais pessoais
- [ ] Verificar se a senha está funcionando corretamente
- [ ] Conferir agenda do dia (horários e clientes confirmados)
- [ ] Verificar se há comandas abertas de dias anteriores
- [ ] Abrir caixa (se for responsável pelo atendimento ao público)
- [ ] Verificar estoque de produtos utilizados (cera, gel, pomada)
- [ ] Confirmar horários dos profissionais do dia
- [ ] Verificar notificações pendentes no sistema

### Recepcionista

- [ ] Login no sistema com credenciais pessoais
- [ ] Verificar se a senha está funcionando corretamente
- [ ] Conferir agenda do dia completa (todos os profissionais)
- [ ] Verificar comandas abertas e status de cada
- [ ] Abrir caixa (se for responsável pelo financeiro)
- [ ] Verificar estoque de produtos para venda
- [ ] Confirmar horários de todos os profissionais do dia
- [ ] Verificar notificações pendentes no sistema

### Gerente

- [ ] Login no sistema com credenciais pessoais
- [ ] Verificar se a senha está funcionando corretamente
- [ ] Conferir agenda do dia completa (todos os profissionais)
- [ ] Verificar comandas abertas e status de cada
- [ ] Abrir caixa (se for responsável pelo financeiro)
- [ ] Verificar estoque completo (produtos e insumos)
- [ ] Confirmar horários de todos os profissionais do dia
- [ ] Verificar notificações pendentes no sistema
- [ ] Revisar relatório do dia anterior
- [ ] Verificar pendências financeiras

## Checklist de Fechamento de Caixa (Detalhado)

### Etapa 1 — Preparação
- [ ] Todas as comandas do dia foram finalizadas
- [ ] Nenhum atendimento está em andamento
- [ ] Pagamentos pendentes foram resolvidos

### Etapa 2 — Conferência de Valores
- [ ] Contar dinheiro em caixa
- [ ] Conferir transações PIX recebidas
- [ ] Conferir transações de cartão (crédito/débito)
- [ ] Conferir pagamentos via app/wallet
- [ ] Verificar se há divergências

### Etapa 3 — Sangrias e Reforços
- [ ] Registrar sangrias realizadas durante o dia
- [ ] Registrar reforços recebidos durante o dia
- [ ] Conferir valores de sangrias e reforços

### Etapa 4 — Fechamento no Sistema
- [ ] Acessar módulo de fechamento de caixa
- [ ] Inserir valores contados manualmente
- [ ] Conferir divergências entre sistema e conferência manual
- [ ] Justificar divergências (se houver)
- [ ] Confirmar fechamento

### Etapa 5 — Relatório
- [ ] Gerar relatório de fechamento
- [ ] Verificar resumo (total vendas, despesas, saldo)
- [ ] Assinar relatório (digital ou físico)
- [ ] Arquivar relatório para consulta futura

## Checklist de Auditoria

- [ ] Verificar logs de auditoria (quem acessou o quê e quando)
- [ ] Conferir transações financeiras (valores batem com relatórios)
- [ ] Verificar permissões de acesso (cada usuário tem acesso adequado)
- [ ] Revisar acessos (usuários ativos vs funcionários ativos)
- [ ] Verificar integridade dos dados (sem registros órfãos)
- [ ] Conferir alterações de preço (histórico de mudanças)
- [ ] Verificar exclusões de registros (há justificativa?)
- [ ] Revisar horários de login/logout da equipe

---

## Checklist de Segurança

- [ ] Senhas fortes (mínimo 8 caracteres, maiúscula, número, símbolo)
- [ ] Sessões ativas revisadas (usuários logados autorizados)
- [ ] Acessos autorizados (ninguém com permissão indevida)
- [ ] Logs verificados (atividades suspeitas identificadas)
- [ ] Backup confirmado (último backup realizado com sucesso)
- [ ] Credenciais de API protegidas (não expostas em código)
- [ ] Ambiente de produção isolado (sem dados de teste)
- [ ] Certificado SSL válido (HTTPS ativo)

---

## Checklist de Implantação

### Cadastros Iniciais
- [ ] Dados cadastrais da barbearia inseridos (nome, CNPJ, endereço)
- [ ] Profissionais cadastrados (nome, cargo, especialidades)
- [ ] Serviços configurados (nome, duração, preço, comissão)
- [ ] Produtos cadastrados (nome, preço, estoque, fornecedor)

### Configurações
- [ ] Permissões definidas por cargo
- [ ] Configurações gerais (horário de funcionamento, fuso horário)
- [ ] Formas de pagamento habilitadas (dinheiro, PIX, cartão)
- [ ] Regras de comissão configuradas

### Testes
- [ ] Teste completo de fluxo (agendamento → atendimento → pagamento)
- [ ] Teste de fechamento de caixa
- [ ] Teste de relatórios
- [ ] Teste de acesso mobile (se aplicável)

### Treinamento
- [ ] Treinamento da equipe realizado
- [ ] Manual de uso disponível
- [ ] Canal de suporte definido
- [ ] Primeiro dia de operação supervisionado
