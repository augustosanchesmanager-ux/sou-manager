## 3. Interpretação

O `401` é **falha de identidade** (não de permissão de banco — o `42501` para `anon` confirma o
hardening correto). O defeito real estava no consumidor: sem trava de sessão, sem tratamento
terminal e sem deduplicação. A tela `booking-settings` apenas revela o sintoma; o disparo é do
`AuthContext`.

## 4. Correção aplicada (F-01)

Arquivo: `context/AuthContext.tsx` (+ `context/AuthContext.test.ts`).

1. **Trava de sessão (`isSessionUsableForAccessContext`)** — a RPC só é chamada com
   `access_token` presente e fora da janela de expiração (`SESSION_EXPIRY_SKEW_SECONDS = 30`).
   Token expirado (aba inativa) passa pelo `getSession()`/auto-refresh; refresh falho **não**
   dispara `signOut()`.
2. **`401` ≠ `403` (`classifyAuthFailure`)** — `401`/`PGRST301` → `unauthenticated`: terminal,
   corta fallbacks e encerra a sessão local uma única vez (`signOut({ scope: 'local' })`).
   `403`/`42501` → `forbidden`: terminal, corta fallbacks, **não** encerra sessão (protege
   onboarding/`AcceptInvite`).
3. **Single-flight por token (`useRef`)** — elimina a dupla chamada da carga fria e absorve
   eventos repetidos; limpeza obrigatória no `finally` (erros transitórios voltam a ser
   tentáveis) e reset no `SIGNED_OUT`/`signOut()`.
4. **Circuit breaker por token** — token que falhou de forma terminal não é re-tentado até
   novo token ou novo mount.
5. **Sem amplificação** — em falha terminal, `profiles`/`staff`/`get_my_pending_invite_token`
   não são chamados.

## 6. GAP

1. Não foi possível determinar qual dos dois corpos de `401` (`42501` anon vs `PGRST301` JWT) é
   o do ambiente do PO; a correção cobre ambos.
2. O caminho `403` (`forbidden`) foi validado por teste unitário do classificador, não por
   resposta real do servidor.
3. `F-02` (guard do outbox por validade, não presença) e `F-03` (drift de schema exposto:
   `.env.local` aponta para projeto cujo default é `api`, fazendo `.rpc()` sem `Accept-Profile`
   cair em `404 PGRST202`) permanecem abertos.
4. `E-7` (identidade instável de `refreshAccessContext`) permanece aberto.
