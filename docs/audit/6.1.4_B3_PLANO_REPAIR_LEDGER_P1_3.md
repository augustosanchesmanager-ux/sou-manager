## 9. Item 7 — Confirmação técnica: registrar como applied NÃO executa DDL/DML

- `supabase migration repair --status applied <version>` (e o INSERT manual equivalente) opera **exclusivamente na tabela de metadados** `supabase_migrations.schema_migrations`.
- O CLI lê o respaldo local da migration apenas para **anotar** o registro (versão/nome/statements); **não executa** o conteúdo SQL contra o banco.
- `schema_migrations` é consultada pelo CLI para decidir o que o **próximo `db push`** deve aplicar — marcar `20260905000000` como applied apenas remove essa versão do conjunto "pendente". **Nenhum efeito em objetos, dados, grants ou policies.**
