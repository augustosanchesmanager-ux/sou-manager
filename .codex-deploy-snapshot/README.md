# SMG - Barber - Sistema de Gestão para Barbearias e Estética

O **SMG - Barber** é uma plataforma completa e inteligente para gestão de negócios do setor de beleza. Utilizando inteligência artificial para gerar insights estratégicos, o sistema ajuda a otimizar processos, fidelizar clientes e aumentar a lucratividade.

## 🚀 Como Iniciar

### Pré-requisitos

- Node.js
- Conta no Supabase
- Chave de API Google Gemini

### Execução Local

1. Instale as dependências: `npm install`
2. Configure o arquivo `.env.local` com suas chaves.
3. Inicie o servidor: `npm run dev`
